# AJDEV — Alberto Junior Portfolio

Personal portfolio for Alberto Junior, an Informatics and Computer Engineering student transitioning from hospitality into technology and engineering.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
The project is static HTML/CSS/JavaScript and can be deployed directly to Vercel, Netlify or GitHub Pages.

## Main files
- `index.html` — portfolio content and lightweight interactions
- `style.css` — responsive black-and-white design
- `assets/imgs/alberto-profile.png` — profile illustration

## Project links
Selected Work now includes four projects in a horizontal carousel: Full House Memory Game, Steak Cuts Experience, Image Processing — 3D Optics Lab, and Discover Lisboa. The first three open their live GitHub Pages deployments; Discover Lisboa remains marked as deployment coming soon.
